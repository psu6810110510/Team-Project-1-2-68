# Born2Code Institute (Learning Management System)

ยินดีต้อนรับสู่โปรเจกต์ **Born2Code** LMS! นี่คือแพลตฟอร์มเว็บแอปพลิเคชันแบบ Full-stack สำหรับจัดการและให้บริการคอร์สเรียนออนไลน์ โดยมีระบบที่ครอบคลุมตั้งแต่การเลือกซื้อคอร์ส, การเรียนผ่านวิดีโอ/เอกสาร PDF, ระบบสอบออนไลน์พร้อมการวิเคราะห์จุดอ่อนเสริมความเข้าใจ, การออกใบประกาศนียบัตรออโต้ และระบบหลังบ้านสำหรับแอดมินและผู้สอน

## 🌟 ความสามารถของเว็บไซต์ (Features)

### ฝั่งผู้เรียน (Student Features)
- **ระบบสมาชิก:** รับรองการสมัครสมาชิกและเข้าสู่ระบบด้วยความปลอดภัยสูง ผ่าน JWT (JSON Web Token)
- **คลังคอร์สเรียน:** ค้นหาคอร์สเรียน กรองตามหมวดหมู่ ดูรายละเอียดคอร์ส และผู้สอน
- **ระบบสั่งซื้อ (E-Commerce):** ซื้อคอร์สเรียนด้วยตนเอง แนบสลิปโอนเงินผ่านระบบ และรอแอดมินอนุมัติผ่านหน้าเว็บ
- **ห้องเรียนอิเล็กทรอนิกส์ (E-Learning):** เรียนรู้ผ่านวิดีโอหลักสูตรและสามารถดาวน์โหลดเอกสารประกอบการเรียน (PDF)
- **ระบบสอบออนไลน์ (Online Examination):** 
  - ทำแบบทดสอบก่อนเรียน (Pre-test) หลังเรียน (Post-test) หรือควิซ (Quiz)
  - คำนวณคะแนนสอบและเปอร์เซ็นต์แบบเรียลไทม์ทันทีที่ส่งข้อสอบ
  - **✨ จุดเด่น:** ระบบ **วิเคราะห์จุดอ่อน (Weakness Analytics)** ที่จะสรุปว่าการทำข้อสอบผิดพลาดไปในหัวข้อย่อย (Lesson) ใดบ้าง ช่วยให้ผู้เรียนทราบว่าตนเองควรกลับไปทบทวนเนื้อหาส่วนไหน
- **ระบบใบประกาศนียบัตร (Certifications):** เมื่อเรียนจบถึงเกณฑ์ ระบบจะสร้างใบประกาศอัตโนมัติสวยงามพร้อมลายเซ็น สามารถกดสั่งปริ้นหรือดาวน์โหลดทางเบราว์เซอร์ได้ทันที
- **จัดการโปรไฟล์ส่วนตัว:** สามารถแก้ไขข้อมูลส่วนตัว อัปโหลดรูปโปรไฟล์ แนะนำตัว และเปลี่ยนรหัสผ่านได้

### ฝั่งแอดมินและผู้สอน (Admin / Teacher Features)
- **Dashboard วิเคราะห์ภาพรวม:** ดูสถิติการใช้งานโดยรวม คอร์สที่ขายดี และนักเรียนที่ลงทะเบียนล่าสุด
- **จัดการเนื้อหาคอร์ส:** สร้าง/แก้ไข/ลบคอร์สเรียนและบทเรียน อัปโหลดรูปภาพปกคอร์สวิดีโอหรือไฟล์เนื้อหา
- **จัดการข้อสอบแบบตอบโต้:** 
  - สร้างข้อสอบระดับคอร์สเรียน หรือผูกไว้กับระดับบทเรียน
  - เพิ่มข้อสอบแบบหลายตัวเลือก (Multiple Choice) ควบคุมคะแนนแต่ละข้อและเลือกข้อที่ถูกต้องได้
- **จัดการการเงินและอนุมัติ:** ตรวจสอบสลิปการโอนเงินของนักเรียน กดยืนยัน (Approve) เพื่อเปิดสิทธิ์การเข้าเรียนอัตโนมัติ หรือปฏิเสธ (Reject)
- **จัดการผู้ใช้งาน:** จัดการรหัสผ่าน บทบาท และสถานะนักเรียน หรือเพิ่มอาจารย์ผู้สอนคนใหม่เข้าสู่ระดับบริหาร

## 🚀 เทคโนโลยีที่เลือกใช้ (Technology Stack)

### Frontend (ระบบหน้าบ้าน)
- **Framework:** [React v18](https://react.dev/) พร้อม [Vite](https://vitejs.dev/) เพื่อความเร็วในการรัน
- **Routing:** [React Router v7](https://reactrouter.com/) สำหรับจัดการหน้าเว็บ
- **Styling:** Custom CSS ร่วมกับ Lucide React (Icons) และ Phosphor Icons
- **Data Visualization:** [Recharts](https://recharts.org/) (สำหรับสร้างกราฟใยแมงมุมวิเคราะห์จุดอ่อนของนักเรียนและสถิติให้แอดมิน)
- **E2E Testing:** Playwright สำหรับทำ Automated Testing

### Backend (ระบบหลังบ้าน)
- **Framework:** [NestJS v11](https://nestjs.com/) โครงสร้าง Backend แข็งแกร่งแบบ Enterprise
- **Database:** PostgreSQL คู่กับ [TypeORM](https://typeorm.io/) สำหรับ Object-Relational Mapping
- **Authentication:** Passport.js, JWT, และ bcrypt (สำหรับการเข้ารหัสรหัสผ่านที่ปลอดภัย)
- **File Uploads:** Multer (รองรับการจัดการสลิปธนาคาร, หน้าปกคอร์ส, ไฟล์รูปโปรไฟล์, วิดีโอ และ PDF)
- **Storage:** เก็บไฟล์และให้บริการแบบ Static สู่หน้าเว็บโดยตรง

## ⚙️ วิธีติดตั้งและใช้งานในเครื่อง (Local Setup)

โครงสร้างโฟลเดอร์รันแยกกัน 2 ส่วนคือ `frontend` และ `backend` กรุณาเปิด Terminal 2 หน้าต่าง

### สิ่งที่ต้องมี
- Node.js (แนะนำ v18 ขึ้นไป)
- PostgreSQL Database หรือ Docker สำหรับจำลองฐานข้อมูล

### 1. ฐานข้อมูล (ตั้งค่าผ่าน Docker)
หากมี Docker แนะนำให้ดึงฐานข้อมูลขึ้นมาโดยรันคำสั่งนี้ที่โฟลเดอร์หลักของโปรเจกต์:
```bash
docker-compose up -d
```

### 2. รันระบบ Backend
1. cd เข้าสู่โฟลเดอร์หลังบ้าน:
   ```bash
   cd backend
   ```
2. ติดตั้งแพ็กเกจทั้งหมด:
   ```bash
   npm install
   ```
3. สร้างและตั้งค่าไฟล์ `.env` ตามสภาพแวดล้อมฐานข้อมูลของคุณ เช่น:
   ```env
   DB_HOST=localhost
   DB_PORT=5432
   DB_USERNAME=postgres
   DB_PASSWORD=yourpassword
   DB_NAME=born2code
   JWT_SECRET=supersecret
   ```
4. กดรันแอปพลิเคชัน:
   ```bash
   npm run start:dev
   ```

### 3. รันระบบ Frontend
1. เปิด Terminal ใหม่แล้วเข้าไปยังโฟลเดอร์หน้าบ้าน:
   ```bash
   cd frontend
   ```
2. ติดตั้งแพ็กเกจทั้งหมด:
   ```bash
   npm install
   ```
3. สร้างและตั้งค่าไฟล์ `.env` เพื่อชี้ทางไปหา Backend:
   ```env
   VITE_API_URL=http://localhost:3000
   ```
4. กดรันแอปพลิเคชัน:
   ```bash
   npm run dev
   ```

ระบบหน้าบ้านจะเข้าได้ที่ลิงก์ `http://localhost:5173`. 

## 📁 โครงสร้างโปรเจกต์ (Directory Structure)

- `/backend` - โมดูล API ต่างๆ ผ่าน NestJS (auth, courses, exams, payments, users, uploads)
- `/frontend` - ระบบหน้าบ้าน React ที่มีหน้าตาแอปพลิเคชันและการสื่อสาร API
- `docker-compose.yml` - ตัวช่วยติดตั้ง PostgreSQL ผ่าน Docker แบบรวดเร็ว
